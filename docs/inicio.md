# OBJETIVO

Este projeto tem como objetivo desenvolver uma API REST para o projeto [My Class](https://github.com/JoaoVitorDomingos/My-Class) e praticar meus estudos sobre API Design.

# TECNOLOGIAS

A API será desenvolvida em **NODE.JS**.

# MODELAGEM

A principal etapa do projeto será a modelagem da API, utilizando conceitos como:

- REST Principles
- URI Design
- Resouce Modeling
- Naming Conventions
- CRUD OPERATIONS
- entre outros

Todo diagrama desenhado será salvo em uma pasta chamada `diagramas/`.

# DESENVOLVIMENTO

Toda etapa de desenvolvimento será documentada para posterior desenvolvimento.
